# Извлечение текста и диктовка

### Извлечение текста

Нажмите `Super + Ctrl + PrtScr`, чтобы выделить область на экране для извлечения текста. Открытая OCR-модель tesseract затем быстро преобразует выделенную область в текст и поместит его в буфер обмена. После этого просто нажмите `Super + V`, чтобы вставить его.

Это очень удобно, чтобы вытаскивать адреса из подвалов изображений или номера телефонов, встроенные в заголовки сайтов.

### Диктовка

На свежих установках [Superwhisper](https://superwhisper.com/) — это бэкенд диктовки по умолчанию, использующий облачную обработку без загрузки офлайн-моделей. Выберите Superwhisper, [Voxtype](https://voxtype.io/) или [Hex](https://anoma.ly/hex/) через _Setup > Defaults > Dictation_ в меню Collie. Выбор бэкенда при необходимости установит его и сделает бэкендом диктовки по умолчанию. Voxtype загружает базовую английскую модель, которая занимает 150MB; модель можно сменить с помощью `voxtype setup model`, а остальные настройки — через `~/.config/voxtype/config.toml`. Superwhisper открывает свои настройки, чтобы выбрать облачную или локальную обработку, а OPR поддерживает приложение в актуальном состоянии. Hex загружает свою модель распознавания речи, работающую на устройстве, во время настройки и работает как пользовательская служба `hex.service`; откройте его окно через значок в трее на панели или выполнив `hex`, чтобы сменить модель и другие настройки.

Вы диктуете, удерживая `Right Alt` или переключая режим с помощью `Alt + Space`, и надиктованный текст появится в области ввода, находящейся в фокусе. Эти сочетания используют выбранный бэкенд. Right Alt также запускает диктовку при использовании в аккорде с модификатором; для таких аккордов используйте Left Alt. В раскладках клавиатуры, где Right Alt — это AltGr, используйте `Alt + Space`, чтобы AltGr оставался доступен для ввода текста. Установки, сделанные до того, как Alt + Space стал сочетанием по умолчанию, сохраняют `F9` для push-to-talk и `Super + Ctrl + X` для переключения, добавленные в `~/.config/hypr/bindings.lua`; удалите их там, чтобы вернуть эти клавиши приложениям.

Одни и те же сочетания работают с каждым бэкендом. Выберите бэкенд через Setup > Defaults > Dictation. Установщик бэкенда настраивает его и сохраняет выбор. Выполните `collie default dictation`, чтобы увидеть, какой бэкенд выбран. Выбор сохраняется в `~/.config/collie/defaults/dictation`. Свежие установки автоматически выбирают Superwhisper.

Collie автоматически загружает десктопную интеграцию выбранного бэкенда. Никакой конфигурации Superwhisper в `~/.config/hypr/` не требуется.

Пользовательские привязки и скрипты могут использовать `collie dictation start`, `collie dictation stop` и `collie dictation toggle`. Выбранный бэкенд выполняет запись и транскрипцию. Выбор Superwhisper отключает его нативное сочетание для удержания и устанавливает его нативное сочетание переключения на `Ctrl + Alt + Space`, отделяя его от клавиш записи Collie. Superwhisper требует как минимум одно нативное сочетание для записи, а его сочетание отмены остаётся доступным.

Дополнительные бэкенды могут интегрироваться без изменения Collie. Предоставьте исполняемый файл с именем `collie-dictation-<backend>` в PATH, который принимает `start`, `stop` и `toggle` и завершает работу немедленно, возвращая ненулевой статус при сбое. Его установщик настраивает провайдер и вызывает `collie-dictation-use <backend>` после успешной настройки. Это останавливает предыдущий бэкенд и атомарно сохраняет выбор; `stop` должен завершаться успешно, когда провайдер простаивает или недоступен. Имена бэкендов используют строчные буквы, цифры и дефисы. Предоставьте `collie-install-dictation-<backend>` для настройки; `collie default dictation <backend>` запускает его. Добавьте пункт в меню Defaults через расширение меню Collie, чтобы вызывать этот переключатель. Необязательная десктопная интеграция может находиться в `${XDG_CONFIG_HOME:-$HOME/.config}/<backend>/shortcuts.lua`.
