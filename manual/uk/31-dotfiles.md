# Dotfiles

Collie налаштовується переважно через так звані дотфайли, що живуть у `~/.config`. Вони вважаються твоїми файлами для твоїх змін. Файли, що живуть у `/usr/share/collie`, належать самій Collie, і тобі не варто в них лізти. Якщо тобі треба щось змінити в `/usr/share/collie`, натомість слід перевизначити значення в `~/.config`.

Ключові конфіги можна редагувати прямо з меню Collie (`Super + Space`), наприклад _Налаштування > Клавіатура > Комбінації клавіш_, _Налаштування > Введення_ та _Налаштування > Конфіг > [файл]_. Коли робиш це в такий спосіб, будь-який процес, який треба перезапустити після редагування конфігів, автоматично перезапуститься після того, як ти вийдеш з редактора (за замовчуванням Neovim — `:wq`, памʼятаєш! — але це можна змінити через _Налаштування > Типові > Редактор_).

Ось список ключових файлів у `~/.config` і того, чим вони керують:

| Файл | Призначення |
| ----------------------- | --------------------- |
| `~/.config/hypr/hyprland.lua` | Головний конфіг Hyprland. Завантажує типові налаштування Collie плюс твої файли перевизначень нижче. [Докладніше про конфіги Hyprland](https://wiki.hypr.land/Configuring/). |
| `~/.config/hypr/bindings.lua` | Твої власні комбінації клавіш і перевизначення типових. |
| `~/.config/hypr/monitors.lua` | Налаштування моніторів, яких не охоплює панель моніторів, як-от поворот, додаткові режими або залишення монітора вимкненим. |
| `~/.config/hypr/input.lua` | Керує розкладкою клавіатури, налаштуваннями миші та трекпада. |
| `~/.config/hypr/looknfeel.lua` | Керує відступами, рамками, анімаціями та рештою вигляду. |
| `~/.config/hypr/autostart.lua` | Керує додатковими процесами, що запускаються разом із сесією. |
| `~/.config/collie/shell.json` | Керує оболонкою Collie: розташуванням панелі, компонуванням і віджетами, а також часом заставки, блокування та простою. |
| `~/.config/foot/foot.ini` | Керує твоїм терміналом (за замовчуванням foot). |
| `~/.XCompose` | Визначає твої емодзі швидкого доступу та автодоповнення імені/адреси електронної пошти. Не забудь запустити `collie-restart-xcompose` після внесення змін. |

Якщо зрештою внесеш багато змін, щоб налаштувати власну систему, варто зробити резервну копію всіх цих дотфайлів. [Stow — чудовий спосіб це зробити](https://www.youtube.com/watch?v=NoFiYOqnC4o).

### Запуск власних застосунків разом із сесією

Якщо хочеш, щоб щось запускалося щоразу, коли ти входиш у систему, — демон синхронізації, застосунок для чату, власний скрипт — помісти це в `~/.config/hypr/autostart.lua`:

```lua
o.launch_on_start("my-service")
```

Це запускає команду як частину сесії, тож вона належно прибирається, коли ти знову виходиш із системи.

### Запуск скриптів за системними подіями

Collie запускає хуки в кілька моментів, і ти можеш навісити на них власні скрипти. Вони живуть у `~/.config/collie/hooks/<event>.d/`, по одному каталогу на подію, і кожен виконуваний файл звідти запускається, коли подія відбувається:

| Подія | Коли запускається |
| ----- | ------------ |
| `post-boot` | Одразу після запуску робочого столу |
| `post-update` | Ближче до кінця `collie update`, після пакетів, міграцій і перезапусків служб, перед оновленням інструментів mise |
| `pre-refresh-pacman` | Після того як `collie refresh pacman` повторно синхронізує конфігурацію пакетів, перед оновленням пакетів; перемикання каналу запускає його під час того самого кроку оновлення |
| `theme-set` | Після зміни теми (назва теми в `$1`) |
| `font-set` | Після зміни шрифту (назва шрифту в `$1`) |
| `battery-low` | Коли заряд батареї стає низьким (відсоток у `$1`) |

Хук `pre-refresh-pacman` — це місце, куди належать користувацькі репозиторії або рядки `IgnorePkg`, оскільки він запускається перед транзакцією пакетів. Обидва повʼязані з оновленням хуки запускаються від імені твого користувача після того, як Collie очищає кешовану авторизацію sudo, тож хуку, який використовує `sudo`, потрібна власна авторизація, і він може попросити твій пароль.

У кожному з цих каталогів уже лежить файл `.sample`, який показує форму хука, — прибери `.sample` з назви, щоб він запрацював. Щоб встановити скрипт, написаний деінде, використай `collie hook install post-boot ~/my-hook`, який копіює його туди та робить виконуваним.

### Додавання власних пунктів меню

Меню Collie (`Super + Space`) можна розширити власними рядками, відредагувавши `~/.config/collie/extensions/collie-menu.jsonc`. Записи ключуються за крапковим id, і саме id розміщує їх у дереві, тож `personal` зʼявляється в кореневому меню, а `personal.notes` — всередині нього:

```jsonc
"personal": {"icon":"","label":"Personal"},
"personal.notes": {"icon":"󰎞","label":"Notes","action":"collie-launch-editor ~/notes"},
```

Повторно використай наявний id, і ти перевизначиш той рядок замість додавання нового. Файл постачається з усіма доступними полями, задокументованими як коментарі.

### Додавання власних експортів оболонки, функцій та аліасів

Collie постачається з купою ергономічних аліасів і корисних функцій, але дуже часто хочеться додати власні. І аліаси, і функції, і експорти слід додавати в `~/.bashrc`. Цей файл не перезаписуватиметься під час оновлень. Якщо хочеш змінити будь-які типові налаштування Collie, їх також можна безпечно додати сюди.

### Налаштування змінних середовища для робочого столу

Експорти сесії робочого столу належать у `~/.config/uwsm/env.d/`. Ці файли запускаються перед запуском твого робочого столу, тож помилка оболонки може відправити тебе назад на екран входу. Тримай відкритим робочий термінал, поки редагуєш їх. Щоб вимкнути перевизначення, перемісти його з `env.d`. Див. [відновлення входу](45-troubleshooting.md#my-password-is-accepted-but-i-return-to-the-login-screen), якщо зміна заважає увійти.

### Зміна внутрішніх файлів Collie

Слухай, це твій компʼютер. Можеш робити з ним усе, що хочеш, але я б радив не вносити зміни безпосередньо у файли в `/usr/share/collie`. Вони належать пакету pacman Collie, тож твої зміни просто перезапишуться під час наступного оновлення. Натомість краще просто перевизначити будь-які типові значення, які тобі не подобаються, у папці `~/.config/*`.

Майже все можна змінити в такий спосіб, як-от типові комбінації клавіш. Просто відредагуй `~/.config/hypr/bindings.lua`, щоб, скажімо, замінити [Obsidian](https://obsidian.md/) на [Joplin](https://joplinapp.org/) (встанови командою `collie-pkg-add joplin-bin`):

```lua
o.rebind("SUPER + SHIFT + O", "Joplin", "joplin-desktop")
```

`o.rebind` видаляє наявну привʼязку перед додаванням заміни. Він приймає ті самі аргументи, що й `o.bind`, включно з помічниками запуску та опціями привʼязки. Використовуй `o.bind`, щоб додати привʼязку, або `hl.unbind`, щоб видалити її без заміни.

Якщо вперто хочеш хакнути внутрішні файли Collie, перемкнися на канал dev через _Оновлення > Канал > Dev_. Це повʼязує Collie з git-копією вихідного коду в `~/collie`, яку ти вільний змінювати скільки душі завгодно. Ніхто тут не вказуватиме тобі, що робити!

### Скидання будь-яких змін

Якщо зрештою наробиш безладу в конфігураціях, завжди можеш повернути їх до типових через _Оновлення > Конфіг_ у меню Collie. Або запустивши `collie reinstall configs`, щоб скинути все.
